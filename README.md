# Discord/YouTube EN→RU переводчик (консольная версия)

Полностью на Python, без сборки C++, без MSYS2/MinGW, без VB-Cable.
Работает через WASAPI loopback — слышит то же самое, что играет у вас
в наушниках, не перехватывая и не отключая звук.

## Установка (обычный Windows Python, НЕ MSYS2!)

1. Установите Python 3.10–3.12 с [python.org](https://www.python.org/downloads/)
   (галочка "Add Python to PATH" при установке).
2. Откройте обычный **PowerShell** или **cmd** (не MSYS2-терминал).
3. Перейдите в папку проекта и создайте виртуальное окружение:

```cmd
cd discord-translator
py -3.12 -m venv venv 
venv\Scripts\activate
pip install -r requirements.txt
```

Установка займёт 3–7 минут (faster-whisper и модели скачиваются при первом запуске).

## Запуск

```cmd
python main.py --list
```

Покажет список устройств вывода (loopback). Обычно нужен пункт с названием
вашего физического устройства вывода (динамики/наушники) — не "Микрофон".

Затем запустите с конкретным устройством или без флага (возьмёт устройство
по умолчанию):

```cmd
python main.py --device 0
```

При первом запуске:
- скачается модель Whisper `small` (~500 МБ, один раз, кешируется);
- скачается языковой пакет argos-translate EN→RU (~50 МБ, один раз).

Дальше всё работает офлайн, без интернета.

## Тест

- **Discord**: зайдите в голосовой канал с англоязычным собеседником — переводы
  начнут появляться в консоли, как только он заговорит.
- **YouTube**: откройте любое видео на английском в браузере — тот же эффект,
  источник звука для программы один и тот же (системный вывод).

## Если распознаётся с задержкой / криво режутся фразы

В `main.py` подстройте параметры:
- `Segmenter(aggressiveness=2, silence_ms=700)` — `aggressiveness` 0..3 (насколько
  строго отсекать не-речь), `silence_ms` — сколько тишины ждать перед тем как
  считать фразу законченной. Меньше `silence_ms` = быстрее реакция, но фразы
  режутся чаще на середине.
- `--model base` вместо `small` — если распознавание не успевает за речью.

## Следующий шаг: оверлей поверх Discord

Когда консольная версия устроит по качеству, MVP легко расширяется до
прозрачного окна-оверлея (всегда поверх окон, без рамки) на PyQt6 или tkinter —
логика захвата/распознавания/перевода остаётся той же, меняется только вывод
(вместо `print()` — обновление текста в окне). Спросите отдельно, если нужно —
соберу и это.
