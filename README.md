# 🎧 VOICE_COCKS — переводчик Discord / YouTube (EN → RU) в реальном времени

![Version](https://img.shields.io/github/v/release/Anti6ot/Voice_Cocks)
![Downloads](https://img.shields.io/github/downloads/Anti6ot/Voice_Cocks/total)
![License](https://img.shields.io/github/license/Anti6ot/Voice_Cocks)

![Демонстрация работы](docs/demo.gif)

**Переводчик речи в реальном времени** для Discord, YouTube и любых других приложений.
Захватывает системный звук, распознаёт английскую речь и выводит перевод на русский
в виде субтитров поверх всех окон. Всё работает **локально**, без облачных API.

---

## ✨ Возможности

- 🎧 **Захват системного звука** через WASAPI Loopback — работает с любым приложением (Discord, Zoom, YouTube, Twitch, игры).
- 🗣️ **Распознавание речи** на базе `faster-whisper` (модели `tiny` / `base` / `small` / `medium`).
- 🌐 **Мгновенный перевод** EN → RU через `ctranslate2` + `opus-mt-en-ru`.
- 🖥️ **Прозрачный overlay субтитров** поверх всех окон, включая игры.
- ⚙️ **Окно настроек** — выбор устройства вывода и модели распознавания.
- 📌 **Всегда поверх окон**, можно двигать и растягивать.
- 🔒 **100% локальная обработка** — звук и текст не покидают компьютер.

### Технологический стек

| Компонент | Технология |
|---|---|
| Захват звука | `PyAudioWPatch` (WASAPI Loopback) |
| Распознавание речи | `faster-whisper` (CTranslate2) |
| Перевод | `ctranslate2` + `opus-mt-en-ru` |
| Сегментация речи | `webrtcvad-wheels` |
| Связь | `websockets` (WebSocket) + `http.server` |
| Overlay | `Electron` (Chromium) |

## 🚀 Установка

### Вариант A — готовый установщик (рекомендуется)

1. Скачай последний релиз `VoiceCocks Setup *.exe` со страницы [Releases](https://github.com/Anti6ot/Voice_Cocks/releases).
2. Установи и запусти.
3. Выбери устройство и модель → готово, субтитры появятся внизу экрана.

### РЕКОМЕНДОВАННЫЙ Вариант B — из исходников (одним кликом) ЕСЛИ Exeшник битый

1. Установи Python 3.12, Node.js LTS и Git.
2. Клонируй репозиторий:

```bash
git clone https://github.com/Anti6ot/Voice_Cocks.git
cd Voice_Cocks
```

3. Запусти:

```bash
.\start_electron.bat
```

`start_electron.bat` сам найдёт Python 3.12, создаст `venv`, установит зависимости и Electron, и запустит приложение.

При первом запуске автоматически скачаются:
- модель перевода `opus-mt-en-ru` (~160 МБ);
- модель распознавания `faster-whisper` (размер зависит от выбранной).

Это может занять **3–5 минут**.

> ⚠️ Если Electron не устанавливается (ошибка `Electron failed to install correctly`), выполни:
> ```bash
> cd overlay\node_modules\electron
> node install.js
> cd ..\..
> ```

## 🎮 Использование

1. Запусти приложение (`start_electron.bat` или установленный `.exe`).
2. Дождись окна **⚙ Настройки**.
3. Выбери устройство вывода и модель распознавания.
4. Нажми **«Применить и перезапустить»**.
5. Появятся консоль «Субтитры и перевод» и прозрачный overlay субтитров.

### Управление overlay

| Действие | Как |
|---|---|
| Перетащить | потянуть за верхнюю полоску окна |
| Растянуть | потянуть за уголок в правом нижнем углу |
| Поверх всех окон | включено всегда |
| Закрыть | закрой консоль «Субтитры и перевод» — overlay закроется автоматически через несколько секунд |

## ⚙️ Настройки

### Выбор устройства

Приложение захватывает звук **устройств вывода** (наушники, колонки) через WASAPI Loopback.
Переводится всё, что играет на компьютере: голос в Discord, видео на YouTube, подкасты, игры.

### Выбор модели распознавания

| Модель | Размер | Скорость | Точность |
|---|---|---|---|
| `tiny` | ~40 МБ | ⚡ Очень быстро | ⭐⭐ |
| `base` | ~75 МБ | ⚡ Быстро | ⭐⭐⭐ |
| `small` | ~250 МБ | 🐢 Средне | ⭐⭐⭐⭐ |
| `medium` | ~770 МБ | 🐌 Медленно | ⭐⭐⭐⭐⭐ |

> 💡 Для игр и Discord — `tiny` или `base`. Для лекций и подкастов — `small` или `medium`.

## 🐛 Решение проблем

### «Устройства не найдены»

Убедись, что есть работающие устройства вывода: **Параметры → Звук → Вывод**.

### «Модель перевода не найдена»

Удали папку `models/opus-mt-en-ru` и перезапусти приложение — модель скачается заново.

### «Ошибка загрузки Electron»

```bash
cd overlay\node_modules\electron
node install.js
```

### «Перевод обрывается на длинных фразах»

Увеличь `max_utterance_ms` в `server.py`:

```python
segmenter = Segmenter(aggressiveness=2, silence_ms=1000, max_utterance_ms=15000)
```

### «Overlay не появляется поверх полноэкранной игры»

Используй режим **«Окно без рамки»** (Borderless), а не «Эксклюзивный полный экран» — в нём ни одно приложение не может рисовать поверх игры.

### «Низкая скорость перевода»

Используй модель `tiny` или `base`.
